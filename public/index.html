Résultat

Le Markdown est modifiable : vos retouches sont prises en compte pour la copie, le téléchargement et l'aperçu.

Historique

    API

    Utilisez url2mark depuis vos scripts :

    curl "/api/convert?url=https://exemple.com&format=text"
    curl -X POST /api/convert \
  -H "content-type: application/json" \
  -d '{"url":"https://exemple.com","links":"reference","frontmatter":true}'

    Paramètres : url ou html, readability, title, frontmatter, images, tables (true/false), links (inline/reference/none), format (json/text).
